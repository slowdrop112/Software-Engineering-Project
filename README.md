## 🚀 Cum să începi (Getting Started)

### Prerechizite
1.  Visual Studio 2022 (sau VS Code).
2.  Acces la internet (pentru conectarea la Azure SQL).

### Configurare Bază de Date
Proiectul folosește o bază de date găzduită în cloud pe Azure.
⚠️ **Important:** Nu urcați Connection String-ul cu parola în fișierele publice de pe Git!

Pentru a rula aplicația local, cereți Connection String-ul de la administratorul bazei de date și adăugați-l în fișierul local de configurare (ex: `appsettings.json` sau `User Secrets`).
